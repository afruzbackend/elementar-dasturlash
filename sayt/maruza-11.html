Arifmetik operatorlar yordamida hisoblash dasturlarini tuzish

Slaydlarda Chop etish

Maqsad: O‘quvchilarga arifmetik operatorlar, qisqartirilgan qiymat berish operatorlari va matematik funksiyalardan foydalanib, formulaga asoslangan chiziqli hisoblash dasturlarini tuzish bo‘yicha bilim berish.

Reja:
  1. Hisoblash dasturining tuzilishi: kiritish, hisoblash va chiqarish bosqichlari
  2. Qisqartirilgan qiymat berish operatorlari va matematik funksiyalar (round, abs, math moduli)
  3. // va % yordamida o‘lchov birliklarini o‘zgartirish va sonni raqamlarga ajratish

1. Hisoblash dasturining tuzilishi: kiritish, hisoblash va chiqarish bosqichlari

Hisoblash dasturining tuzilishi

Ko‘pchilik hisoblash masalalari chiziqli algoritm bilan yechiladi: buyruqlar yuqoridan pastga bir marta bajariladi. Bunday dastur uch qismdan iborat: boshlang‘ich ma’lumotlarni kiritish, formula bo‘yicha hisoblash va natijani chiqarish. Dasturni yozishdan oldin masalaning matematik modelini — ya’ni formulasini aniqlab olish kerak.

Formulani ifodaga o‘girish qoidalari

  • Ko‘paytirish belgisi — matematikadagi 2a yozuvi Pythonda albatta 2 * a ko‘rinishida yoziladi.
  • Kasr chiziq — (a + b) / 2 kabi surat va maxrajni qavsga olish shart; a + b / 2 boshqa natija beradi.
  • Daraja — x² yozuvi x ** 2, kvadrat ildiz esa math.sqrt(x) yoki x ** 0.5 ko‘rinishida yoziladi.
  • Tushunarli nomlar — o‘zgaruvchilarga a, b emas, imkon qadar narx, soni, tezlik kabi nomlar bering.
KodNatija / izoh
narx = 250000Xizmat narxi, so‘m
chegirma = 15Chegirma foizi
tolov = narx * (100 - chegirma) // 100Chegirmadan keyingi summa
print(f"To‘lov: {tolov} so‘m")To‘lov: 212500 so‘m

Bu misolda butun bo‘lish ishlatilgani uchun natija butun son bo‘ldi. Agar narx * (100 - chegirma) / 100 yozilsa, natija 212500.0 ko‘rinishida chiqadi.

2. Qisqartirilgan qiymat berish operatorlari va matematik funksiyalar (round, abs, math moduli)

Qisqartirilgan qiymat berish operatorlari

O‘zgaruvchining qiymatini o‘zi asosida yangilash juda ko‘p uchraydi: x = x + 5. Buni qisqa yozish uchun qo‘shma operatorlar mavjud.

Qisqa yozuvTo‘liq yozuvx = 10 bo‘lganda natija
x += 5x = x + 515
x -= 3x = x - 37
x *= 2x = x * 220
x /= 4x = x / 42.5
x //= 3x = x // 33
x %= 3x = x % 31

O‘rnatilgan va math moduli funksiyalari

  • abs(x) — modul (absolyut qiymat): abs(-7) natijasi 7.
  • round(x, n) — n xonagacha yaxlitlash: round(3.14159, 2) natijasi 3.14. Diqqat: round(2.5) natijasi 2, round(3.5) esa 4 — Python o‘rtadagi qiymatni eng yaqin juft songa yaxlitlaydi.
  • min() va max() — eng kichik va eng katta qiymat: max(4, 9, 2) natijasi 9.
  • import math — matematik modulni ulaydi; shundan so‘ng math.sqrt(16) natijasi 4.0, math.pi esa 3.141592653589793.
KodNatija / izoh
import mathModul dastur boshida bir marta ulanadi
a, b, c = 3, 4, 5Uchburchak tomonlari
p = (a + b + c) / 2Yarim perimetr: 6.0
s = math.sqrt(p * (p - a) * (p - b) * (p - c))Geron formulasi
print("Yuza:", s)Yuza: 6.0

Dasturni tekshirish uchun natijasi oldindan ma’lum bo‘lgan qiymatlarni tanlash qulay: tomonlari 3, 4 va 5 bo‘lgan to‘g‘ri burchakli uchburchak yuzasi 3 * 4 / 2 = 6 ga teng. Dastur ham 6.0 chiqarsa, formula to‘g‘ri yozilgan. Keyin istalgan boshqa qiymatlarni input() orqali kiritish mumkin.

3. // va % yordamida o‘lchov birliklarini o‘zgartirish va sonni raqamlarga ajratish

Birliklarni o‘zgartirish

// va % operatorlari birga ishlatilganda katta qiymatni bir nechta birlikka ajratish mumkin. Masalan, fayl yuklab olish 3725 sekund davom etdi; buni soat, daqiqa va sekundga ajratamiz. 1 soat = 3600 sekund, 1 daqiqa = 60 sekund.

KodNatija / izoh
t = 3725Jami sekundlar
soat = t // 36001
daqiqa = t % 3600 // 60125 // 60 = 2
sekund = t % 605
print(f"{soat} soat {daqiqa} daqiqa {sekund} sekund")1 soat 2 daqiqa 5 sekund

Sonni raqamlarga ajratish

Uch xonali sonning raqamlarini ajratish ham xuddi shu usulga asoslanadi: % 10 oxirgi raqamni beradi, // 10 esa oxirgi raqamni olib tashlaydi.

Kodn = 472 bo‘lganda
birlar = n % 102
onlar = n // 10 % 107
yuzlar = n // 1004
print("Raqamlar yig‘indisi:", birlar + onlar + yuzlar)Raqamlar yig‘indisi: 13

Tipik xatolar

  • Qavs tushib qolishi — (a + b) / 2 o‘rniga a + b / 2 yozish noto‘g‘ri natija beradi, lekin xato xabari chiqmaydi.
  • import math unutilishi — math.sqrt() ishlatilganda NameError: name 'math' is not defined xatosi chiqadi.
  • Kasr natijani butun deb kutish — / har doim float beradi; butun natija kerak bo‘lsa, // yoki int() ishlating.
