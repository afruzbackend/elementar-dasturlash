Arifmetik va mantiqiy operatorlar

Slaydlarda Chop etish

Maqsad: O‘quvchilarga Python tilidagi arifmetik, taqqoslash va mantiqiy operatorlar, ularning natija turlari hamda ifodada amallarning bajarilish ustuvorligi bo‘yicha nazariy bilim berish.

Reja:
  1. Arifmetik operatorlar: +, -, *, /, //, %, **
  2. Taqqoslash operatorlari va mantiqiy (bool) qiymatlar
  3. Mantiqiy operatorlar and, or, not va amallarning bajarilish ustuvorligi

1. Arifmetik operatorlar: +, -, *, /, //, %, **

Operator va operand

Operator — qiymatlar ustida bajariladigan amal belgisi, operand esa shu amal bajariladigan qiymat. Masalan, 7 + 2 ifodasida + operator, 7 va 2 operandlar. Operatorlar va operandlardan tuzilgan yozuv ifoda deyiladi; Python ifodani hisoblab, bitta natija qaytaradi.

Bo‘lishning uch ko‘rinishi

  • / (oddiy bo‘lish) — natija har doim float: 10 / 2 natijasi 5.0, butun son emas.
  • // (butun bo‘lish) — natija kichik tomonga yaxlitlanadi: 17 // 5 natijasi 3, -7 // 2 natijasi esa -4.
  • % (qoldiq) — bo‘lishdan qolgan qism: 17 % 5 natijasi 2. Son juftligini tekshirishda ishlatiladi: n % 2 natijasi 0 bo‘lsa, son juft.
  • Nolga bo‘lish — 5 / 0, 5 // 0 va 5 % 0 ifodalari ZeroDivisionError xatosini beradi.

Hayotiy misol: 100 ta kompyuterni 8 ta xonaga teng taqsimlash kerak. 100 // 8 natijasi 12 — har xonaga 12 tadan kompyuter, 100 % 8 natijasi 4 — ortib qolgan kompyuterlar soni. int va float aralashsa, natija float bo‘ladi: 3 + 2.0 natijasi 5.0.

2. Taqqoslash operatorlari va mantiqiy (bool) qiymatlar

Taqqoslash operatorlari

Taqqoslash operatorlari ikki qiymatni solishtiradi va natijada mantiqiy qiymat — True (rost) yoki False (yolg‘on) qaytaradi. Bu qiymatlar bool turiga tegishli va keyinchalik shart hamda takrorlash operatorlarining asosini tashkil etadi.

OperatorMa’nosiMisolNatija
==Teng5 == 5True
!=Teng emas5!= 3True
>Katta2 > 7False
<Kichik2 < 7True
>=Katta yoki teng18 >= 18True
<=Kichik yoki teng9 <= 8False

Taqqoslashning o‘ziga xos jihatlari

  • = va == farqi — bitta tenglik qiymat berish, ikkita tenglik esa solishtirish: x = 5 o‘zgaruvchiga qiymat beradi, x == 5 esa tekshiradi.
  • Zanjirli taqqoslash — 1 < x < 10 yozuvi «x 1 dan katta va 10 dan kichik» degan ma’noni beradi.
  • Satrlarni solishtirish — katta-kichik harf farqlanadi: "Admin" == "admin" natijasi False.
  • Turli turlar — 5 == 5.0 natijasi True, lekin 5 == "5" natijasi False, chunki biri son, ikkinchisi satr.

Taqqoslash natijasini o‘zgaruvchiga saqlash ham mumkin: kattami = yosh >= 18. Shundan so‘ng print(kattami) yosh qiymatiga qarab True yoki False chiqaradi.

3. Mantiqiy operatorlar and, or, not va amallarning bajarilish ustuvorligi

Mantiqiy operatorlar

Bir nechta shartni birlashtirish uchun mantiqiy operatorlar ishlatiladi. and (va) — ikkala shart ham rost bo‘lganda True; or (yoki) — kamida bittasi rost bo‘lsa True; not (emas) — qiymatni teskarisiga aylantiradi. Masalan, Wi-Fi tarmog‘iga ulanish uchun tarmoq nomi to‘g‘ri VA parol to‘g‘ri bo‘lishi kerak — bu and ga misol.

ABA and BA or B

not operatori bitta operand bilan ishlaydi: not True natijasi False, not False natijasi True. Misol: x = 15 bo‘lsa, x > 10 and x % 2 == 0 natijasi False (15 toq), x > 10 or x % 2 == 0 natijasi True.

Amallar ustuvorligi

  • Qavslar ( ) ichidagi amallar.
  • Darajaga oshirish **.
  • Unar minus (-x).
  • *, /, //, %.
  • +, -.
  • Taqqoslash: ==,!=, <, >, <=, >=.
  • not, so‘ng and, eng oxirida or.
