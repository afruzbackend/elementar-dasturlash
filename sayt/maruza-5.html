1. Python interpretatorini o‘rnatish va ishlashini tekshirish

Dasturlash muhiti nima?

Python kodini bajarish uchun kompyuterda interpretator o‘rnatilgan bo‘lishi kerak. Kod yozish, saqlash, ishga tushirish va xatolarni ko‘rish uchun qulay dastur esa dasturlash muhiti (IDE — Integrated Development Environment) deyiladi. Boshlovchilar uchun eng qulay muhitlar: Python bilan birga o‘rnatiladigan IDLE, o‘quvchilar uchun maxsus yaratilgan Thonny va professional muharrir Visual Studio Code.

Windows da Pythonni o‘rnatish

  • Brauzerda rasmiy sayt python.org ni ochib, Downloads bo‘limidan Windows uchun so‘nggi Python 3 o‘rnatuvchisini yuklab olish.
  • Yuklangan faylni ishga tushirish.
  • Birinchi oynaning pastidagi «Add python.exe to PATH» belgisini albatta yoqish.
  • «Install Now» tugmasini bosib, o‘rnatish tugashini kutish.
  • «Setup was successful» xabari chiqqach, «Close» tugmasini bosish.

O‘rnatish to‘g‘riligini tekshirish uchun Win + R tugmalarini bosib, cmd deb yozing va Enter ni bosing. Ochilgan buyruq satrida python --version buyrug‘ini kiriting. Agar «Python 3.12.4» kabi javob chiqsa, interpretator ishlayapti. Agar buyruq tanilmasa, demak o‘rnatishda PATH belgisi yoqilmagan — o‘rnatuvchini qayta ishga tushirib, «Modify» orqali tuzatish mumkin.

Thonny muhiti thonny.org saytidan yuklab olinadi va ichida tayyor Python interpretatori bo‘ladi, ya’ni alohida o‘rnatish talab qilinmaydi. Uning afzalligi — dasturni qadamma-qadam bajarib, har bir o‘zgaruvchi qiymatini maxsus oynada kuzatish imkoniyati. Bu boshlovchilarga kod qanday ishlashini ko‘z bilan ko‘rishga yordam beradi.

2. Idle muhiti: interaktiv rejim va skript (fayl) rejimi

IDLE: interaktiv rejim

IDLE ni Pusk menyusidan «IDLE (Python 3.x)» nomi orqali ochish mumkin. Ochilgan oyna Python Shell deyiladi, unda >>> belgisi ko‘rinadi. Bu interaktiv rejim: buyruq yozib Enter bosilsa, natija darhol chiqadi. Bu rejim Pythonni kalkulyator sifatida ishlatish va kichik buyruqlarni sinab ko‘rish uchun qulay.

Kod (>>> dan keyin)Natija / izoh
2 + 35
7 / 23.5 — bo‘lish natijasi kasr son
10 - 4 * 22 — avval ko‘paytirish bajariladi
"Salom" * 3'SalomSalomSalom' — matn 3 marta takrorlanadi
print("IT-servis")IT-servis

E’tibor bering: interaktiv rejimda ifoda natijasi print() siz ham ko‘rinadi. Ammo bu rejimda yozilgan kod saqlanmaydi — oyna yopilsa, hammasi yo‘qoladi.

IDLE: skript (fayl) rejimi

  • Python Shell oynasida File → New File (Ctrl + N) ni tanlash — bo‘sh muharrir oynasi ochiladi.
  • Kodni yozish.
  • File → Save (Ctrl + S) orqali faylni .py kengaytmasi bilan saqlash, masalan, birinchi.py.
  • Run → Run Module (F5) orqali ishga tushirish — natija Python Shell oynasida chiqadi.

3. Birinchi oddiy kodlar va ularni ishga tushirish

Birinchi dastur

Dasturlash an’anasiga ko‘ra birinchi dastur ekranga salom chiqaradi. Quyidagi kodni yangi faylga yozib, salom.py nomi bilan saqlang va F5 ni bosing:

KodNatija / izoh
# Mening birinchi dasturimIzoh — bajarilmaydi
print("Assalomu alaykum!")Assalomu alaykum!
print("Men Python o‘rganyapman.")Men Python o‘rganyapman.
print("Bir yilda", 365 * 24, "soat bor")Bir yilda 8760 soat bor

print() funksiyasiga vergul bilan bir nechta qiymat berilsa, ular orasiga avtomatik bitta bo‘sh joy qo‘yiladi. Qo‘shtirnoq ichidagi matn o‘zgarishsiz chiqadi, qo‘shtirnoqsiz yozilgan ifoda esa avval hisoblanadi.

Boshlovchilar ko‘p qiladigan xatolar

  • Faylni saqlamasdan F5 bosish — IDLE avval saqlashni so‘raydi; fayl nomida bo‘sh joy va kirill harflaridan qoching.
  • Faylni python.py yoki print.py deb nomlash — standart modul nomlari bilan to‘qnashuv yuzaga kelishi mumkin.
  • Qo‘shtirnoqni yopmaslik — SyntaxError xatosi chiqadi.
  • Interaktiv rejimdagi >>> belgisini faylga ko‘chirish — bu belgi kodning qismi emas.
