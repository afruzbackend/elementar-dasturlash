1. Blok-sxema bloklarining python operatorlariga mos kelishi

Blokdan buyruqqa

Yaxshi tuzilgan blok-sxema — tayyor dasturning «chizmasi». Uni Python ga o‘girish deyarli mexanik ish: har bir blok bitta yoki bir nechta buyruqqa aylanadi, strelkalar esa buyruqlar tartibini belgilaydi. Asosiy diqqat ikki joyga qaratiladi: romb tarmoqlari chekinish bilan ajratiladi, qaytish strelkasi esa sikl bo‘lib qoladi.

O‘girish qoidalari

  • O‘zgaruvchi nomlari: blok-sxemadagi nomlarni o‘zgartirmang — kodni algoritm bilan solishtirish oson bo‘ladi.
  • Turlar: son kiritilsa, int() yoki float() ni unutmang.

3. Amaliy mashq: takrorlanuvchi algoritm asosida dastur yozish va sinash

Amaliy mashq: haftalik internet trafigi

Kerakli jihozlar: Python 3 o‘rnatilgan kompyuter, oldingi darsdagi trafik blok-sxemasi. Xavfsizlik: dasturni saqlashdan oldin fayl nomini tekshiring (trafik.py), boshqa o‘quvchining faylini o‘chirmang. Blok-sxemadagi «kun <= 7?» romb va qaytish strelkasi for sikliga aylanadi.

  • Dasturni blok-sxema bo‘yicha yozing va har bir satr qaysi blokka tegishli ekanini izoh (#) bilan belgilang.
  • 3, 6, 4.5, 7, 2, 5, 8 qiymatlari bilan sinang: Jami: 35.5 Gb, O‘rtacha: 5.07 Gb, oshgan kunlar: 3.
  • Barcha kunlar 5 Gb bo‘lsa, oshgan kunlar 0 bo‘lishini tekshiring — 5 limitdan oshmaydi.
  • Natijani oldingi darsdagi qo‘lda tekshiruv bilan solishtiring.
  • Manfiy qiymat kiritilsa, «Xato qiymat» deb qayta so‘raydigan tekshiruv qo‘shing.

AMALIY TOPSHIRIQ

Oldingi darsda o‘zingiz chizgan blok-sxema bo‘yicha Python dasturini yozing. Har bir satrga blok raqamini izoh sifatida qo‘shing, kamida ikkita istisno holatni (nol, manfiy son, katta-kichik harf) tekshiruvchi shart qo‘shing va dasturni kamida 4 ta test qiymati bilan sinab, natijani qo‘lda tekshiruv bilan solishtiring. Qo‘shimcha topshiriq: ax² + bx + c = 0 kvadrat tenglamani yechuvchi dastur (a = 0, D > 0, D = 0, D < 0 holatlari bilan; masalan, 1, -3, 2 → 2.0 va 1.0). Baholash: algoritmga moslik, chekinish, istisno holatlarning hisobga olingani va test natijalari asosida.
