1. Matematik formulani python ifodasiga aylantirish qoidalari va math moduli

Masaladan dasturgacha

Har qanday hisoblash masalasi bir xil bosqichlarda yechiladi: 1) kirish ma’lumotlari (nima beriladi?), 2) natija (nima topilishi kerak?), 3) formula (ular qanday bog‘langan?), 4) dastur, 5) tekshiruv. Dastur yozishdan oldin kamida bitta misolni daftarda qo‘lda hisoblab qo‘yish kerak — aks holda dastur natijasi to‘g‘rimi yoki yo‘qmi, bilib bo‘lmaydi.

Operatorlar ustuvorligi

  • Darajaga ko‘tarish ko‘paytirish, bo‘lish va hatto unar minusdan oldin bajariladi: -5 ** 2 natijasi -25.
  • Qavslar ustuvorlikni o‘zgartiradi: (-5) ** 2 natijasi 25.
  • Ko‘paytirish va bo‘lish qo‘shish va ayirishdan oldin: 2 + 3 * 4 → 14, (2 + 3) * 4 → 20.
  • Kasr chizig‘i dasturda qavs bilan almashtiriladi: (a + b) / 2, aks holda faqat b ikkiga bo‘linadi.

2. Hisoblash masalalarini yechish: yuza, vaqt, ma’lumot hajmi va raqamlar bilan ishlash

Keys 1. Uchburchak yuzi (Geron formulasi)

Tomonlari a, b, c bo‘lgan uchburchak uchun yarim perimetr p = (a + b + c) / 2, yuza S = √(p(p − a)(p − b)(p − c)).

KodNatija / izoh
import mathModulni ulash
a, b, c = 3, 4, 5Tomonlar
p = (a + b + c) / 2p = 6.0
s = math.sqrt(p * (p - a) * (p - b) * (p - c))√36
print("Yuza:", s)Yuza: 6.0

Keys 2. Soniyalarni soat, daqiqa va soniyaga ajratish

Server ishlagan vaqt soniyalarda berilgan: sek = 3725. Butun bo‘linma va qoldiq yordamida: soat = sek // 3600 → 1; daq = sek % 3600 // 60 → 2; s = sek % 60 → 5. Natija: «1 soat 2 daqiqa 5 soniya».

Keys 3. Faylni yuklab olish vaqti

Hajmi 700 MB bo‘lgan faylni 20 Mbit/s tezlikda yuklash vaqti: 1 bayt = 8 bit bo‘lgani uchun t = 700 * 8 / 20 = 280.0 soniya. Uni int(t // 60) va int(t % 60) yordamida «4 daqiqa 40 soniya» ko‘rinishiga keltiramiz. Birliklarni moslashtirmaslik — eng ko‘p uchraydigan xato: megabayt va megabitni chalkashtirsak, javob 8 marta farq qiladi.

Keys 4. Uch xonali son raqamlari

n = 375 uchun: yuzlar n // 100 → 3, o‘nlar n // 10 % 10 → 7, birlar n % 10 → 5; raqamlar yig‘indisi 15. Bu usul raqamlarni ajratishda satrga aylantirmasdan ishlaydi.

3. Amaliy mashq: kvadrat tenglamani yechuvchi dastur va natijani tekshirish

Amaliy mashq: kvadrat tenglama

Kerakli jihozlar: Python 3 o‘rnatilgan kompyuter, kalkulyator, daftar. Xavfsizlik: ko‘z bilan ekran orasidagi masofa 50–70 sm bo‘lsin, ish tugagach dasturni saqlab, muhitni yoping. ax² + bx + c = 0 tenglamasi diskriminant D = b² − 4ac orqali yechiladi.

KodNatija / izoh (a=1, b=-5, c=6)
import math
a = float(input("a = ")); b = float(input("b = ")); c = float(input("c = "))Koeffitsiyentlar
D = b ** 2 - 4 * a * cD = 1.0
if D > 0:Ikki ildiz
    x1 = (-b + math.sqrt(D)) / (2 * a)x1 = 3.0
    x2 = (-b - math.sqrt(D)) / (2 * a)x2 = 2.0
    print("x1 =", x1, "x2 =", x2)
elif D == 0:Bitta ildiz
    print("x =", -b / (2 * a))
else:D < 0
    print("Haqiqiy ildiz yo‘q")
  • Kodni kv_tenglama.py nomi bilan saqlang va 1, -5, 6 qiymatlari bilan ishga tushiring.
  • D = 0 holatini 1, -4, 4 bilan sinang: x = 2.0 chiqishi kerak.
  • D < 0 holatini 1, 2, 5 bilan sinang: «Haqiqiy ildiz yo‘q» chiqishi kerak.
  • Har bir natijani ildizlarni tenglamaga qo‘yib qo‘lda tekshiring.

AMALIY TOPSHIRIQ

Keys kartochkasidagi uchta masalani dasturlang: 1) Geron formulasi bilan uchburchak yuzi (3, 4, 5 → 6.0); 2) soniyalarni soat, daqiqa va soniyaga ajratish (3725 → 1 soat 2 daqiqa 5 soniya); 3) kvadrat tenglama (D > 0, D = 0, D < 0 holatlari).
